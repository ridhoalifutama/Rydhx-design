# Rydhx Design System

Dokumentasi design system dan konsep landing page responsif untuk Rydhx.

## Menjalankan secara lokal

```sh
npm install
npm run dev
```

Vite akan menampilkan alamat lokal untuk membuka halaman `rydhx-design-system.html`.

## Build produksi

```sh
npm run build
```

Output build dibuat di `dist/` dan tidak disimpan ke repository. Dependensi Lucide dan Phosphor digunakan untuk ikon; Plus Jakarta Sans dan Instrument Serif dimuat melalui Google Fonts.

Konten layanan, harga, portofolio, dan kanal order masih berupa konsep sampai materi final Rydhx tersedia.
